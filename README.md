# Real-Time Chat Application (MERN Stack)

A **real-time one-to-one chat application** built with the MERN stack and Socket.IO, featuring authentication, media sharing, and online/offline presence.

---

## 🚀 Features

- **Real-time chat** using Socket.IO with online/offline user presence
- **Authentication** via Clerk with webhooks for secure login and session handling
- **Message persistence** in MongoDB for offline chat delivery
- **Image sharing** via Cloudinary
- **User search & filters** for easy contact discovery
- **Theme-based React UI** built with DaisyUI for responsive and modern design

---

## 🧠 Tech Stack

### Frontend
- React
- DaisyUI (TailwindCSS)

### Backend
- Node.js
- Express.js
- Socket.IO

### Database & Storage
- MongoDB
- Cloudinary (for image storage)

### Authentication
- Clerk (email/password + OAuth)
- Webhooks for user session handling
